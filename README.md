# Física da Princesinha 👑

App de estudo de Física (Óptica + Movimento Circular) num único `index.html`.
É só abrir o arquivo no navegador, sem instalar nada. O progresso fica salvo no próprio aparelho.

- Mundo 1, Óptica (prof. Luiz): Refração, Lentes, Óptica da Visão
- Mundo 2, Movimento Circular (prof. Héric): MCU, Transmissão, Dinâmica curvilínea
- Extras: Flashcards, Resumão, Simulado (15 questões), Checklist do livro, modo escuro
